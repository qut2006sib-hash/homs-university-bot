# بوت جامعة حمص

Telegram bot that answers Homs University students only from human-reviewed answers.
It does not invent rules, deadlines, or article numbers.

The project lives in [`homs_university_bot/`](homs_university_bot/).
Installation, tests, and launch commands are in [`homs_university_bot/README.md`](homs_university_bot/README.md).

Do not commit `.env`, the Telegram token, the admin key, or SQLite files.
Synthetic demo data is labelled and blocked unless `HU_ALLOW_SYNTHETIC=1`.
